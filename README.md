# Зірка звіздарів

Ескіз інсталяції до ходи звіздарів: дві фанерні зірки з прорізами-орнаментом на колоді 150×150 мм заввишки 4 м посеред постаменту 3,6×3,6 м. Глядачі обертають зірки знизу двома колесами через шнури й шківи.

## Що тут є

| Файл / папка | Що це |
|---|---|
| `index.html` | Та сама сторінка для GitHub Pages: https://vartanmarkarian.github.io/ZIRKA/ |
| `zirka-eskiz.html` | Інтерактивний ескіз. Відкривається в будь-якому браузері: монтаж на фото, вибір варіантів зірок, діаметра, фарбування й оформлення стійки, креслення, механіка, розкрій, матеріали. |
| `ЧПК_розкрій/` | Файли для фрезерування, SVG і DXF у масштабі 1:1, одиниці — мм. |
| `_генератор/` | Python-скрипти, якими згенеровано зірки, розкрій і сторінку. |
| `photo_2026-10-28_18-34-28.jpg` | Фото постаменту, на якому зроблено ескіз. |

## Зірки

- Велика: «Рожа» (12 променів), «Колосок» (16), «Сонце» (20), а також у дусі українського модерну й народного різьблення «Модерн» (12), «Крин» (12), «Вихор» (12). Ріжеться на 4 однакові чверті, шви йдуть по западинах між променями.
- Передня Ø1200: «Іскра» (16), «Квітка» (10), «Сяйво» (24), «Вихрова» (12), «Тюльпан» (10). Ріжеться цілою з одного листа.
- Фанера ФСФ 10 мм. Перемички між прорізами не вужчі за 25 мм, уздовж швів щонайменше 50 мм під шурупи.

## Файли для ЧПК

- `велика_Ø2400/` … `велика_Ø2960/`: для кожного діаметра є окрема чверть (`…_chvert_x4`, різати 4 шт.) і розкладка двох чвертей на лист 1220×2440 (`…_arkush_1220x2440_2chverti`, потрібно 2 листи). Друга чверть на листі повернута на 180°. Найбільший діаметр: «Рожа» 2510, «Колосок» 2960, «Сонце» 2420, «Модерн» і «Крин» 2480, «Вихор» 2500.
- `передня_Ø1200/`: передні зірки цілими.
- У DXF контур лежить на шарі `CONTOUR`, отвори на шарі `HOLES`. Спершу фрезерують отвори, потім контур.

## Як перегенерувати

Потрібен Python 3 з Pillow (`pip install pillow`). Варіанти орнаменту описані у `_генератор/variants.py`.

```
cd _генератор
python build.py
```

Скрипт перезаписує `zirka-eskiz.html` і всю папку `ЧПК_розкрій`.
